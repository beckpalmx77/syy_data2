Sales Keyword Search API

เอกสารข้อกำหนดทางเทคนิคและคู่มือใช้งาน REST JSON API สำหรับค้นหาประวัติรายการขายสินค้าตามคีย์เวิร์ด (เช่น "2157015" หรือชื่อสินค้า) และรหัสลูกค้า คืนค่าข้อมูล วันที่, รหัสสินค้า, ราคาขาย, จำนวน, ส่วนลด, สต๊อกคงเหลือ และรายละเอียดอื่นๆ

Status: Active Content-Type: application/json Normalized Pattern Matching

1. แนวคิดและเป้าหมาย (Concept & Objectives)

บริการ REST API นี้สร้างขึ้นเพื่อให้พนักงานขายหรือระบบภายนอก (เช่น Mobile App, CRM, POS) สามารถค้นหาประวัติการซื้อขายสินค้าย้อนหลังได้อย่างรวดเร็ว จากการพิมพ์คีย์เวิร์ดรหัสสินค้า หรือขนาดยาง/ยี่ห้อ (เช่น พิมพ์ "2157015" ระบบจะจับคู่ตรงกับ "215/70R15" หรือ "215-70-15" โดยอัตโนมัติ)


คุณสมบัติหลักของ Sales Keyword Search API:

  • Smart Pattern Matching: ค้นหาแบบ LIKE ทั้งบนรหัสสินค้า (`SKU_CODE`), ชื่อสินค้า (`SKU_NAME`) และชื่อที่ตัดอักขระพิเศษ (Slash `/`, Dash `-`, Space ` `) เพื่อความสะดวกในการพิมพ์ค้นหา
  • Customer Filter: รองรับการระบุรหัสลูกค้า (`ar_code` เช่น "KS-อ003783") หรือชื่อลูกค้าเพื่อเจาะจงค้นหาประวัติซื้อขายของลูกค้ารายนั้นๆ
  • Required Minimum Fields: ส่งคืนข้อมูลสำคัญครบถ้วน: วันที่ (`DI_DATE`), รหัสสินค้า (`SKU_CODE`), ชื่อสินค้า (`SKU_NAME`), ราคาขายต่อหน่วย (`TRD_U_PRC`), จำนวนขาย (`TRD_QTY`), ส่วนลด (`TRD_TDSC_KEYINV`), และสต๊อกคงเหลือปัจจุบัน (`SKU_STOCK`)
  • WITH (NOLOCK) Performance: อ่านข้อมูลประวัติการขายด้วย `WITH (NOLOCK)` ไม่บล็อกการทำงานของระบบหลัก

2. ขั้นตอนการประมวลผลระบบ (Implementation Steps)

การทำงานของไฟล์ API (api/search_sales_keyword_api) มีขั้นตอนหลัก 4 ขั้นตอน ดังนี้:

1
Input Parsing
รับค่า ar_code, keyword และ limit จาก JSON Body หรือ Query String
2
Pattern Normalization
นำคีย์เวิร์ดมาตัดเครื่องหมาย /, - และช่องว่างออก เพื่อสร้างเงื่อนไข SQL Pattern Matching 3 ทิศทาง
3
SQL Query Execution
รัน SQL Join ระหว่าง `DOCINFO`, `ARDETAIL`, `ARFILE`, `TRANSTKH`, `TRANSTKD`, `SKUMASTER` และ `SALESMAN`
4
JSON UTF-8 Formatting
ปรับเครื่องหมายบวก/ลบ สำหรับเอกสารใบลดหนี้ (IS/ISO) และส่งออก JSON UTF-8 สมบูรณ์

3. การยืนยันตัวตน (Authentication & Headers)

Header Key Type คำอธิบาย / ตัวอย่าง
Content-Type string application/json; charset=utf-8
X-API-KEY string รหัสคีย์ยืนยันตัวตนระบบ (ถ้ามี)

4. ข้อกำหนด API Endpoint (Endpoint Specification)

POST / GET /api/search_sales_keyword_api

Request Parameters (Payload / Query String)

Parameter Type Required คำอธิบาย
ar_code string ไม่บังคับ รหัสลูกค้า หรือชื่อลูกค้า (เช่น "KG-0000005" หรือ "ปิยะณัฐ")
keyword string แนะนำ คีย์เวิร์ดรหัสสินค้า ขนาดยาง หรือชื่อสินค้า (เช่น "2157015", "215/70R15", "ATLAS")
limit integer ไม่บังคับ จำนวนรายการที่ต้องการคืนค่า (Default: 50, Max: 500)

6. ตัวอย่างโค้ดเรียกใช้งานจากภายนอก (Code Examples)

cURL Command

  -H "Content-Type: application/json" \
  -d '{
    "ar_code": "KS-อ003783",
    "keyword": "2157015",
    "limit": 50
  }'
JavaScript Fetch API 
async function searchSalesByKeyword() {
  const url = 'http://61.7.142.26:8888/syy_data2/api/search_sales_keyword_api';

  const payload = {
    ar_code: 'KS-อ003783',
    keyword: '2157015',
    limit: 50
  };

  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(payload)
    });

    const result = await response.json();
    console.log('Search Result:', result);
    return result;
  } catch (error) {
    console.error('Error searching sales:', error);
  }
}
Python (requests) 
import requests

url = "http://61.7.142.26:8888/syy_data2/api/search_sales_keyword_api"
headers = {
    "Content-Type": "application/json"
}
payload = {
    "ar_code": "KS-อ003783",
    "keyword": "2157015",
    "limit": 50
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

if data.get("status") == "success":
    print(f"Found Records: {data['total_records']}")
    for item in data["data"]:
        print(item["DI_DATE"], item["SKU_CODE"], item["SKU_NAME"], item["TRD_U_PRC"], item["TRD_QTY"], item["SKU_STOCK"])
else:
    print("API Error:", data.get("message"))

7. รหัสตอบกลับความผิดพลาด (HTTP Status Codes & Errors)

HTTP Code Status สาเหตุ / ความหมาย
200 OK success ค้นหาประวัติรายการขายสำเร็จเรียบร้อย
400 Bad Request error ส่ง Parameter รูปแบบไม่ถูกต้อง
401 Unauthorized error ไม่ได้แนบ API Key หรือ API Key ไม่ถูกต้อง / หมดอายุ
500 Internal Server Error error เกิดข้อผิดพลาดในการเชื่อมต่อฐานข้อมูล SQL Server
