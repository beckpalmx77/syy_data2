Product Category Export API

เอกสารข้อกำหนดทางเทคนิค แนวคิด และคู่มือการใช้งาน REST JSON API สำหรับส่งออกรหัสประเภทสินค้า (`ICCAT_CODE`) และชื่อประเภทสินค้า (`ICCAT_NAME`) ดึงข้อมูลผ่านไฟล์เงื่อนไข `cond_file/query-product-price-main.php`

Status: Active Content-Type: application/json Array & Search Filter Supported

1. แนวคิดและเป้าหมาย (Concept & Objectives)

บริการ REST API นี้จัดทำขึ้นเพื่อให้ระบบภายนอก (เช่น ระบบ E-Commerce, Mobile Sales Application, CRM หรือ BI Dashboard) สามารถดึงหมวดหมู่/ประเภทสินค้าทั้งหมดในระบบไปแสดงผลใน Dropdown หรือใช้สำหรับเป็น Filter ค้นหาสินค้า


คุณสมบัติหลักของ Product Category Export API:

  • Shared Data Condition: เชื่อมตาราง `ICCAT` กับโครงสร้างสินค้าหลักผ่านไฟล์ cond_file/query-product-price-main.php การันตีว่าเป็นประเภทสินค้าที่มีการใช้งานจริงในระบบ
  • Multi-Category Array Filtering: พารามิเตอร์ iccat_code รองรับการค้นหาแบบ Array (เช่น ["603", "101-BS01"]) หรือการค้นหาคำสำคัญ (เช่น "ยาง", "น้ำมัน")
  • WITH (NOLOCK) Performance: ทำงานด้วยคำสั่ง WITH (NOLOCK) ประมวลผลได้อย่างมีประสิทธิภาพสูงสุดโดยไม่ทำให้ฐานข้อมูลเกิด Deadlock
  • Clean JSON Output: คืนค่าเฉพาะ `ICCAT_CODE` และ `ICCAT_NAME` ในรูปแบบ UTF-8 JSON ที่กระชับ ประหยัด Bandwidth

2. ขั้นตอนการประมวลผลระบบ (Implementation Steps)

การทำงานของไฟล์ API (api/export_product_cat_api) มีขั้นตอนหลัก 4 ขั้นตอน ดังนี้:

1
Input Parsing
รับค่า JSON Body (`php://input`) หรือ Query String แปลงพารามิเตอร์ iccat_code เป็น Array เงื่อนไข
2
Query Condition Load
โหลดไฟล์เงื่อนไข cond_file/query-product-price-main.php ที่มี Table Join สินค้าและหมวดหมู่ครบถ้วน
3
SELECT DISTINCT Execution
รันคำสั่ง SELECT DISTINCT ICCAT.ICCAT_CODE, ICCAT.ICCAT_NAME ... ORDER BY ICCAT.ICCAT_CODE ASC ผ่าน PDO Prepared Statement
4
JSON UTF-8 Formatting
แปลงรหัสภาษาไทยเป็น UTF-8 สด และส่งออกด้วย Header Content-Type: application/json; charset=utf-8

3. การยืนยันตัวตน (Authentication & Headers)

การเรียกใช้งาน API ควรส่ง HTTP Request Headers มาตรฐานดังต่อไปนี้:

Header Key Type คำอธิบาย / ตัวอย่าง
Content-Type string application/json; charset=utf-8
X-API-KEY string รหัสคีย์ยืนยันตัวตนระบบ (ถ้ามี)

4. ข้อกำหนด API Endpoint (Endpoint Specification)

POST / GET /api/export_product_cat_api

Request Parameters (Payload / Query String)

Parameter Type Required คำอธิบาย
iccat_code string | array ไม่บังคับ รหัสหรือชื่อประเภทสินค้า
- ส่งเป็น Array: ["603", "101-BS01"]
- ส่งเป็น Comma String: "603, 101-BS01"
- ส่งเป็นคำค้นหา: "ยาง" หรือ "น้ำมัน"
*(หากไม่ส่งมา ระบบจะคืนค่าประเภทสินค้าทั้งหมด)*

JavaScript Fetch API 
async function fetchProductCategories() {
  const url = 'http://61.7.142.26:8888/syy_data2/api/export_product_cat_api';

  const payload = {
    iccat_code: ['603', '101-BS01']
  };

  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(payload)
    });

    const result = await response.json();
    console.log('Product Category API Result:', result);
    return result;
  } catch (error) {
    console.error('Error fetching Product Category API:', error);
  }
}
Python (requests) 
import requests

url = "http://61.7.142.26:8888/syy_data2/api/export_product_cat_api"
headers = {
    "Content-Type": "application/json"
}
payload = {
    "iccat_code": ["603", "101-BS01"]
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

if data.get("status") == "success":
    print(f"Total Product Categories: {data['total_records']}")
    for cat in data["data"]:
        print(cat["ICCAT_CODE"], cat["ICCAT_NAME"])
else:
    print("API Error:", data.get("message"))

7. รหัสตอบกลับความผิดพลาด (HTTP Status Codes & Errors)

HTTP Code Status สาเหตุ / ความหมาย
200 OK success ดึงข้อมูลประเภทสินค้าสำเร็จเรียบร้อย
400 Bad Request error ส่ง Parameter รูปแบบไม่ถูกต้อง
401 Unauthorized error ไม่ได้แนบ API Key หรือ API Key ไม่ถูกต้อง / หมดอายุ
500 Internal Server Error error เกิดข้อผิดพลาดในการเชื่อมต่อฐานข้อมูล SQL Server
