Wholesale Sales Export API

Wholesale Sales Data

บริการส่งออกข้อมูลรายการขายส่ง (Wholesale Sales Data) กรองตามช่วงวันที่ (`doc_date_start` ถึง `doc_date_to`), รหัสเซลส์ (`slmn_name`), ประเภทสินค้า (`iccat_code`) พร้อมข้อมูลรวม 17 ฟิลด์

/api/export_wholesale_api POST
Active v1.0 ดูเอกสารคู่มือ

Customer (AR) Export API

Customer Accounts

บริการดึงข้อมูลรายชื่อและรหัสลูกค้า (Customer Master AR) แยกตามพนักงานขาย/เขตการขาย (`slmn_name`) รองรับการเลือกพร้อมกันหลายเซลส์แบบ Array (`["ก้อย", "น๊อต"]`) ข้อมูลรวม 23 ฟิลด์

/api/export_customer_api POST / GET
Active v1.0 ดูเอกสารคู่มือ

Product Category Export API

Product Categories

บริการดึงรหัสหมวดสินค้า (`ICCAT_CODE`) และชื่อประเภทสินค้า (`ICCAT_NAME`) ดึงผ่านไฟล์เงื่อนไข `cond_file/query-product-price-main` สำหรับนำไปแสดงใน Dropdown หรือ Filter

/api/export_product_cat_api POST / GET
Active v1.0 ดูเอกสารคู่มือ

Sales Keyword Search API

Search & History

บริการค้นหาประวัติการขายสินค้าจากคีย์เวิร์ด (`keyword` เช่น "2157015") และรหัสลูกค้า (`ar_code`) แสดงผลลัพธ์: วันที่, รหัสสินค้า, ชื่อสินค้า, ราคาขาย, จำนวน, ส่วนลด, สต๊อกคงเหลือ

/api/search_sales_keyword_api POST / GET
Active v1.0 ดูเอกสารคู่มือ
