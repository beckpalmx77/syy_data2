Customer Data Export API

เอกสารข้อกำหนดทางเทคนิค แนวคิด และคู่มือการใช้งาน REST JSON API สำหรับส่งออกข้อมูลรหัสลูกค้า รายชื่อลูกค้า ที่อยู่ วงเงินอนุมัติ และผู้ติดต่อ แยกตามชื่อพนักงานขาย/เขตการขาย (Salesman)

Status: Active Content-Type: application/json Multi-Salesman Array Supported

1. แนวคิดและเป้าหมาย (Concept & Objectives)

บริการ REST API นี้จัดทำขึ้นเพื่อให้ระบบภายนอก (เช่น ระบบ CRM, Mobile Sales App, ERP หรือ BI Dashboard) สามารถดึงข้อมูลรายชื่อลูกค้า (Customer Accounts / Accounts Receivable) ที่ดูแลโดยพนักงานขาย/เขตการขายแต่ละท่านได้อย่างรวดเร็วและปลอดภัย


คุณสมบัติหลักของ Customer Export API:

  • Multi-Salesman Selection: พารามิเตอร์ slmn_name รองรับการส่งค่าแบบ Array (เช่น ["ก้อย", "น๊อต"]) เพื่อดึงข้อมูลลูกค้าพร้อมกันมากกว่า 1 เซลล์
  • Active Salesmen Validation: กรองเฉพาะพนักงานขายที่เปิดใช้งานในระบบ (SALESMAN.SLMN_ENABLE = 'Y')
  • WITH (NOLOCK) Performance: อ่านข้อมูลแบบ WITH (NOLOCK) ช่วยให้ดึงข้อมูลได้อย่างรวดเร็ว ไม่บล็อกการทำงานหลักของฐานข้อมูล
  • Comprehensive Customer Profile: คืนค่าข้อมูลครบถ้วน ทั้งรหัสลูกค้า, ชื่อลูกค้า, กลุ่มลูกค้า, ที่อยู่จัดส่ง/วางบิล, เลขผู้เสียภาษี, วงเงินอนุมัติ, เครดิตเทอม และข้อมูลผู้ติดต่อ

2. ขั้นตอนการประมวลผลระบบ (Implementation Steps)

การทำงานของไฟล์ API (api/export_customer_api) มีขั้นตอนหลัก 4 ขั้นตอน ดังนี้:

1
Input Parsing
รองรับ JSON Body (`php://input`) และ Query Params แปลงพารามิเตอร์ slmn_name เป็น Array รายชื่อเซลส์
2
Condition Loading
โหลดไฟล์เงื่อนไขมาตรฐาน cond_file/doc_info_customer_ar.php ที่มี Table Join ครบทั้ง 11 ตารางลูกค้า
3
Dynamic SQL Execution
สร้างเงื่อนไข WHERE SALESMAN.SLMN_ENABLE = 'Y' AND (SLMN_NAME LIKE ...) พร้อมรันผ่าน PDO Prepared Statement
4
JSON UTF-8 Encoding
ตรวจสอบและแปลงข้อความมอก.874/TIS-620 เป็น UTF-8 100% ตอบกลับด้วยโครงสร้าง JSON ที่สะอาดและครบถ้วน

3. การยืนยันตัวตน (Authentication & Headers)

การเรียกใช้งาน API ควรส่ง HTTP Request Headers มาตรฐานดังต่อไปนี้:

Header Key Type คำอธิบาย / ตัวอย่าง
Content-Type string application/json; charset=utf-8
X-API-KEY string รหัสคีย์ยืนยันตัวตนระบบ (ถ้ามี)

4. ข้อกำหนด API Endpoint (Endpoint Specification)

POST / GET /api/export_customer_api

Request Parameters (Payload / Query String)

Parameter Type Required คำอธิบาย
slmn_name string | array ไม่บังคับ ชื่อหรือรหัสพนักงานขาย/เขตการขาย
- ส่งเป็น Array: ["ก้อย", "น๊อต"]
- ส่งเป็น Comma String: "ก้อย, น๊อต"
*(หากไม่ส่งมา ระบบจะคืนค่าข้อมูลลูกค้าทั้งหมดจากเซลส์ที่เปิดใช้งาน)*

6. ตัวอย่างโค้ดเรียกใช้งานจากภายนอก (Code Examples)

cURL Command 
curl -X POST "http://61.7.142.26:8888/syy_data2/api/export_customer_api" \
  -H "Content-Type: application/json" \
  -d '{
    "slmn_name": ["ก้อย", "น๊อต"]
  }'
JavaScript Fetch API 
async function fetchCustomerData() {
  const url = 'http://61.7.142.26:8888/syy_data2/api/export_customer_api';

  const payload = {
    slmn_name: ['ก้อย', 'น๊อต']
  };

  try {
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(payload)
    });

    const result = await response.json();
    console.log('Customer API Result:', result);
    return result;
  } catch (error) {
    console.error('Error fetching Customer API:', error);
  }
}
Python (requests) 
import requests

url = "http://61.7.142.26:8888/syy_data2/api/export_customer_api"
headers = {
    "Content-Type": "application/json"
}
payload = {
    "slmn_name": ["ก้อย", "น๊อต"]
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

if data.get("status") == "success":
    print(f"Total Customers: {data['total_records']}")
    for cust in data["data"]:
        print(cust["AR_CODE"], cust["AR_NAME"], cust["SLMN_NAME"], cust["ADDB_PHONE"])
else:
    print("API Error:", data.get("message"))

7. รหัสตอบกลับความผิดพลาด (HTTP Status Codes & Errors)

HTTP Code Status สาเหตุ / ความหมาย
200 OK success ดึงข้อมูลรายชื่อลูกค้าสำเร็จเรียบร้อย
400 Bad Request error ส่ง Parameter รูปแบบไม่ถูกต้อง
401 Unauthorized error ไม่ได้แนบ API Key หรือ API Key ไม่ถูกต้อง / หมดอายุ
500 Internal Server Error error เกิดข้อผิดพลาดในการเชื่อมต่อฐานข้อมูล SQL Server
